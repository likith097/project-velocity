# Project Velocity — Phase 1

Recruiter-ready React + TypeScript portfolio for Likith Kumar. **Phase 2 3D features are not included.**

## Run locally

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production check

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Push the project folder to a GitHub repository.
2. Import that repository into Vercel.
3. Choose the Vite framework preset (build command `npm run build`, output directory `dist`).
4. Deploy to a preview URL and review before sharing publicly.

**Important:** A standard Vercel preview URL is not automatically access-controlled. Use appropriate deployment protection if strict privacy is required. The included `robots.txt` allows indexing, as requested for eventual public launch. Avoid sharing or indexing a preview until approved.

## Privacy and analytics

- The original resume PDF is included **unchanged**, including the phone number within it, at `public/Likith-Kumar-Resume.pdf`. The phone number is not displayed on the webpage.
- Analytics are **not enabled** in this build. Detailed privacy-conscious analytics require selecting/configuring a provider and verifying its terms and free-tier limits. Do not claim visitor tracking is live before then.
- No contact form or backend is required.

## Content

Professional experience, education, and certifications were adapted from the supplied resume. The work history and metrics reflect that resume and have not been independently verified. Project live/source URLs were supplied in the planning conversation.
